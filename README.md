# hey, mark!

**hey, mark!**는 Tauri와 React로 구축된 현대적이고 가벼운 프리미엄 마크다운 에디터이자 뷰어입니다.

## 주요 특징
- **압도적인 디자인**: 부드러운 애니메이션, 글래스모피즘(Glassmorphism), 그리고 세련된 다크 모드를 지원하는 아름다운 UI.
- **강력한 성능**: Rust 기반의 Tauri 프레임워크를 사용하여 빠르고 메모리 효율적입니다.
- **지능적인 보조**: OpenAI, Claude, Gemini 및 로컬 LLM 연동을 통한 인공지능 글쓰기 보조 기능.
- **타이포그래피 최적화**: 사용자의 가독성을 위해 자간, 행간, 장평을 실시간으로 조절할 수 있습니다.

## 시작하기
1. 프로그램을 실행합니다.
2. `Open Vault`를 클릭하여 마크다운 파일이 포함된 폴더를 선택합니다.
3. 왼쪽 탐색기에서 파일을 선택하여 읽거나 편집합니다.

## 기술 스택
- **Frontend**: React, TypeScript, Vite
- **Backend/Desktop**: Tauri (Rust)
- **Editor**: CodeMirror
- **Viewer**: Markdown-it, Shiki
- **State Management**: Zustand


# hey, mark! v1.0 기능 명세서

현재 버전(v1.0)에서 지원하는 모든 주요 기능은 다음과 같습니다.

### 1. 마크다운 뷰어 (Markdown Viewer)
- **Shiki 엔진 탑재**: 화려하고 정확한 구문 강조(Syntax Highlighting)를 제공합니다.
- **고성능 렌더링**: Markdown-it을 기반으로 한 빠르고 정확한 마크다운 파싱.
- **이미지 최적화**: WebP 형식을 지원하여 이미지 로딩 속도를 극대화했습니다.

### 2. 마크다운 에디터 (Markdown Editor)
- **CodeMirror 기반**: 코드 편집기 수준의 강력한 편집 경험을 제공합니다.
- **실시간 편집 및 저장**: 수정 사항을 즉시 반영하고 안전하게 저장합니다.
- **자동 저장**: 문서 작업 중 데이터 손실을 방지합니다.

### 3. 문서 및 프로젝트 관리
- **탭 시스템**: 여러 문서를 동시에 열고 전환할 수 있는 직관적인 탭 인터페이스.
- **폴더(Vault) 탐색기**: 로컬 폴더를 라이브러리처럼 열어 탐색할 수 있습니다.
- **전역 검색**: 문서 내 텍스트를 빠르게 찾을 수 있는 강력한 검색 기능.
- **북마크**: 자주 사용하는 문서를 즐겨찾기에 등록하여 빠르게 접근할 수 있습니다.
- **탭 일괄 닫기**: 열려 있는 모든 탭을 한꺼번에 닫을 수 있는 기능을 지원합니다.

### 4. 사용자 맞춤 가독성 설정
- **가독성 패널**: 우측 상단 설정을 통해 실시간으로 텍스트 스타일을 조정할 수 있습니다.
    - **자간(Letter Spacing)** 조절
    - **행간(Line Height)** 조절
    - **장평(Horizontal Scale)** 조절
- **다크/라이트 모드**: 주변 환경에 맞춰 테마를 전환할 수 있습니다.
- **스킨 시스템**: UI 전반의 분위기를 바꿀 수 있는 스킨 설정을 지원합니다.

### 5. AI 글쓰기 어시스턴트
- **플로팅 AI 메뉴**: 텍스트 선택 시 나타나는 전용 메뉴를 통해 다음 작업을 수행합니다.
    - **문장 다듬기(Refine)**: 더욱 매끄러운 문장으로 개선합니다.
    - **번역(Translate)**: 한국어/영어 등 자연스러운 번역을 지원합니다.
    - **요약 및 축소(Shorten)**: 핵심 내용을 중심으로 문장을 간결하게 만듭니다.
- **다양한 모델 지원**: OpenAI(GPT), Anthropic(Claude), Google(Gemini), Local LLM(Ollama 등) 연동 가능.

### 6. 편의 기능 및 시스템 통합
- **드래그 앤 드롭**: 외부 파일을 앱으로 끌어다 놓아 즉시 열 수 있습니다.
- **파일 확장자 지원**: `.md` 뿐만 아니라 `.txt`, `.json` 파일의 열람 및 편집을 지원합니다.
- **외부 링크 처리**: 문서 내 링크 클릭 시 시스템 기본 브라우저로 안전하게 연결됩니다.
- **네이티브 성능**: Tauri를 사용하여 가볍고 빠른 성능을 유지합니다.
